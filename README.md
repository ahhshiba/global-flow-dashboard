# 資金流向觀測台

依手寫清單建置：匯市、債市、股市、商品、國家與公司現金流、VIX，從 1995 年開始做 30 年關聯研究，另有「鉅亨每日」分頁每天匯入鉅亨網新聞與報價並自動標註重點。

打開 `dashboard.html` 就能看（單一檔案，資料已內嵌；字型需要網路，離線會退回系統字型）。

## 分頁

| 分頁 | 內容 |
|---|---|
| 總覽 | 資金風險偏好指數（六訊號 z 分數合成）、資金流向排行、狀態分區後報酬、各市場自動重點、資料缺口 |
| 匯市 | 美元指數、美元/台幣・日圓・人民幣、歐元；各國外匯存底；台灣外匯存底月資料 |
| 債市 | 美 3M/5Y/10Y/30Y、日 10Y、台灣重貼現率；10Y−3M 利差；公債與公司債基金；波克夏 |
| 股市 | S&P 500、那斯達克、道瓊、費半、恆生、台灣加權（日經、上證參考）；美／台／港龍頭股各 10 檔 |
| 商品 | 玉米、大豆、小麥、金銀白金、銅鋁鐵礦、原油天然氣；世界銀行商品指數；銅/金、油/金比值 |
| 現金流 | 外國持有美債（TIC）、各國經常帳、美股與台股龍頭的營業／自由現金流 |
| VIX | VIX 月底值、四個區間之後 1／3 個月的資產報酬 |
| 30 年關聯 | 關聯熱圖（全期 vs 近 36 月）、13 組重點配對的滾動相關與領先落後、9 次危機期間各資產表現 |
| 鉅亨每日 | 各市場收盤與異常波動（>2σ）、重點摘要、可搜尋的新聞清單；保留最近 30 天 |

## 指令

```bash
python3 gfd.py all              # 需要時更新歷史（快取 >7 天）→ 分析 → 今日鉅亨 → 產出 dashboard.html
python3 gfd.py history          # 強制重抓 30 年歷史並重算分析（約 2–3 分鐘）
python3 gfd.py analyze          # 只重算分析，不連網
python3 gfd.py daily            # 匯入今天（台北時間）的鉅亨網資料
python3 gfd.py daily --date 2026-09-12
python3 gfd.py daily --backfill 5
python3 gfd.py build            # 只重新產出 dashboard.html
./run_daily.sh                  # 給排程用，log 寫到 logs/daily_YYYYMM.log
```

只用 Python 標準函式庫與 numpy，不需要安裝其他套件。

## 每日自動更新（已安裝，2026-09-15）

crontab 每天跑兩次（安裝前的備份：`~/crontab.bak_20260915_223816_pre_global_flow_dashboard`）：

```
30 7 * * * /home/simon/Desktop/global-flow-dashboard/run_daily.sh    # 美股收盤後：重匯前一天完整新聞＋今天
30 18 * * * /home/simon/Desktop/global-flow-dashboard/run_daily.sh   # 台股收盤、盤後新聞出齊後
```

每次都會更新日線、重算分析、匯入鉅亨網、重新產出 `dashboard.html`；月資料快取超過 7 天才重抓。`run_daily.sh` 有檔案鎖，上一次還沒跑完就略過。log 在 `logs/daily_YYYYMM.log`。要停用就刪掉那兩行 crontab。

線上 Artifact 連結不會被排程自動更新，只有本機檔案會。

## 報價跑馬燈與單一標的線圖

- 分頁列下方的報價跑馬燈會自動循環，滑鼠移上去或按「暫停」就停住；系統設定「減少動態效果」時改成可橫向捲動的靜態列。
- 有「單一標的」按鈕的圖表可以只看一檔，並切換 **日線／週線／月線／年線**，期間選項跟著週期變（日線 1 個月～3 年、週線 1～15 年、月線 5 年～全期）；龍頭股卡片也有。
- 日線保留近 3 年、週線近 15 年，月線與年線從 1995 年起，全部由 Yahoo 日收盤彙整（週線＝該週最後交易日）。日債用日本財務省。
- 期貨的報價單位和世界銀行月均價不同（玉米是美分/蒲式耳，不是美元/公噸），單一標的模式會標出來源與單位。
- 台灣重貼現率、鐵礦砂、世界銀行商品指數、比值類沒有日線來源，只能看月線與年線。

## 設定

所有標的、龍頭股名單、危機區間、關聯配對、重點關鍵字與門檻都在 `gfd/config.py`。

- 龍頭股名單是大型權值股觀察清單，不是即時市值排名。
- 新聞重點：標題命中關鍵字 +2、鉅亨關鍵字命中 +1、鉅亨頭條 +2、提及龍頭股 +1（最多 +2）、標題提到當日異常波動的標的 +2；分數 ≥ `HIGHLIGHT_SCORE`（目前 7）標為重點。
- 異常波動：當日變動 ÷ 近 60 個交易日變動的標準差，絕對值 ≥ `MOVER_Z`（目前 2）。

## 已知缺口

- **台灣／美國前 10 大公司債**：沒有免費的逐券長歷史，改用 VWESX／VWEHX／LQD／HYG 公司債基金。
- **台灣 10 年期公債殖利率**：沒有可程式化的長歷史，改用央行重貼現率。
- **港股公司現金流**、**台灣經常帳**：沒有免費結構化來源。
- **鉅亨網期貨、VIX、公債報價**：鉅亨公開 API 不提供這些代碼，每日頁改用 Yahoo／日本財務省並逐列標註。
- 匯率與商品是月均值，關聯係數會比用月底值略低。

## 檔案

```
gfd.py              CLI
gfd/config.py       標的與規則
gfd/sources.py      各資料來源轉接
gfd/history.py      抓 30 年資料 → data/raw/
gfd/analysis.py     統計與關聯研究 → data/analysis.json
gfd/daily.py        鉅亨每日 → data/daily/YYYY-MM-DD.json
gfd/build.py        內嵌資料 → dashboard.html、dashboard.artifact.html
web/                版面、樣式、前端程式（純 SVG 圖表，無外部函式庫）
```

所有統計都是歷史樣本內的描述，不構成投資建議。
