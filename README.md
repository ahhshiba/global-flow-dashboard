# 資金流向觀測台

依手寫清單建置：匯市、債市、股市、商品、國家與公司現金流、VIX，從 1995 年開始做 30 年的關聯研究（13 組配對的滾動相關與領先落後放在各市場分頁；2026-10-02 起沒有獨立的「30 年關聯」分頁），另有「鉅亨每日」分頁每天匯入鉅亨網新聞與報價並自動標註重點。

**線上 demo：https://ahhshiba.github.io/global-flow-dashboard/** （公開示範版，每天自動更新）

本機打開 `dashboard.html` 就能看（單一檔案，資料已內嵌；字型需要網路，離線會退回系統字型）。

## 版面慣例（2026-10-02）

- **先數字、後說明**：每個分頁開頭一句由資料組出來的結論，方法收在「怎麼算的」；重點數字做成小卡（標籤＋大數字＋一句判讀，判讀色用中性的可信度色，不用漲跌色）；長的句子收在「點開」（`moreBox`、各列的 `details`），用到才看。
- **自動敘述裡的數字加粗**（`emNums`）：+3.3%、r = −0.42、+96bp 這類數字，日期與名稱裡的數字（2025-02、「10 年−3 個月」）不算。
- **總覽「各市場重點」依主題分組**，每組有則數與「看分頁」；傳導鏈改用狀態表（點＝各層，實心＝成立中），訊號劇本每個訊號一行、點開看敘述——這兩組在沙盤推演裡有完整版。
- **推演總結最上面的「可能會發生什麼」（2026-10-03，使用者說看不懂，要「先寫可能會發生什麼，點開再寫原因跟判斷過程」）**：一行一件事——比平常更可能（傳導鏈下一步裡差距 ≥ 10 個百分點的前 4 個）、比平常更不可能（≤ −10 的前 2 個）、還沒有答案的（期望值排行，附判定）；每一行只有白話名稱、長條（機率，細線＝平常）與數字，下跌情境另加一句「如果真的發生：最常一起漲的避險」。點開才有：**為什麼**（哪條鏈、哪幾步已發生、這一步在哪，加一句話原因）、**怎麼判斷的**（過去幾次、6 個月與 12 個月對照平常、中位數第幾個月發生；12 個月和平常差不多時明講「比較早發生，不是比較會發生」）、**可信度**（次數＋對答案的結果）、**如果真的發生，怎麼準備**（避險、換 20% 試算、利率上行時美長債的提醒）。現在正在發生的事收在最後的「根據什麼」。白話名稱與每條鏈的一句話原因在 `web/js/64-story.js`（`SC_PLAIN`、`SC_CHAIN_WHY`），新增訊號或鏈要一起補。原本的卡片原封不動放在「研究細節」分隔線下面。
- **確切標的、低基期、更詳細的推演（2026-10-03）**：`gfd/targets.py`（設定在 `config.TARGETS`、`LOWBASE`），結果在 `scenario.targets`；標的的含息日線由 `history.fetch_targets_daily` 抓（`data/raw/daily_targets.json`，每天更新，38 檔，代碼都用 Yahoo 確認過；台灣債券 ETF 在櫃買，代碼後綴 `.TWO`）。每個抽象資產對應 1～4 檔可以買的 ETF／股票／現金部位（美國＋台灣）。每檔：最新價、1 年、離 3 年高點與歷史高點、10 年位階、離 200 日線；位置標籤（低基期／高檔回落／高基期／中間）；追蹤程度＝和底層資產的月報酬相關（< 0.5 標「追蹤不佳」，例：肥料股和尿素價格 0.0～0.2）。每個資產三個角度各看 3／6／12 個月：模型（沙盤推演的校準值與 80% 區間）、相似時點（亮燈組合和現在重疊 ≥ 25% 的月份之後實際怎樣：典型、10～90%、上漲比例、段數）、低基期（底層序列「當時往前 10 年的位階」分五段，各段之後 6／12 個月；現在在哪一段）；三個角度的方向一致才寫「偏多／偏空」。每個「可能會發生的事」點開多兩段：真的發生時通常多深（剛跨門檻那個月的變動、之後 3 個月內最深的分布）、什麼時候發生（等 1～6 個月的分布）；確切標的（會跟著動的、過去擋得住的）。2026-10-03：位置低的是美長債（TLT／00679B／00687B，10 年位階 1～4%）、日圓（FXY）、天然氣（UNG）、Mosaic；黃金、白銀、白金、台肥是高檔回落。費城半導體三個角度都偏多，但 SOXX 一年漲一倍、位階 99%。全部是歷史統計，不是投資建議。
- **推演總結（研究細節）**：亮著的訊號一列一個（長條＝這一段亮了幾個月，細線＝歷史中位、粗線＝最長），相似時點用點陣對照；傳導鏈的節點用小長條表示機率（細線＝平常），鏈下面是關鍵數字小籤，完整句子在「推演細節」。
- 2026-10-02 改版前後，不用點就看得到的**敘述段落**（不含表格與小卡）：推演總結 7,083 → 約 1,700 字、傳導鏈 1,473 → 431 字、總覽的各市場重點 2,199 → 1,047 字；連表格與小卡全部算的可見文字：推演總結 12,133 → 9,774（−19%）、總覽 4,237 → 3,570、傳導鏈 2,372 → 1,976、訊號劇本持平。頁面高度幾乎沒變——省下的是要讀的句子，不是版面。說明收進「點開」時，會改變結論的限制（樣本外判定、事後設計、樣本內、運氣、統計上站不住）一律留在看得到的地方。

## 指令

```bash
python3 gfd.py all              # 需要時更新歷史（快取 >7 天）→ 分析 → 今日鉅亨 → 產出 dashboard.html
python3 gfd.py history          # 強制重抓 30 年歷史並重算分析（約 2–3 分鐘）
python3 gfd.py analyze          # 只重算分析，不連網
python3 gfd.py daily            # 匯入今天（台北時間）的鉅亨網資料
python3 gfd.py daily --date 2026-09-12
python3 gfd.py daily --backfill 5
python3 gfd.py build            # 只重新產出 dashboard.html
./run_daily.sh                  # 給排程用，log 寫到 logs/daily_YYYYMM.log
```

只用 Python 標準函式庫與 numpy，不需要安裝其他套件。

## 每日自動更新（已安裝，2026-09-15）

crontab 每天跑兩次（安裝前的備份：`~/crontab.bak_20260915_223816_pre_global_flow_dashboard`）：

```
30 7 * * * /home/simon/Desktop/global-flow-dashboard/run_daily.sh    # 美股收盤後：重匯前一天完整新聞＋今天
30 18 * * * /home/simon/Desktop/global-flow-dashboard/run_daily.sh   # 台股收盤、盤後新聞出齊後
```

每次都會更新月資料的當月數字與日線、重算分析、匯入鉅亨網、重新產出 `dashboard.html`；外匯存底、美債持有、公司現金流這類年度資料超過 7 天才重抓。`run_daily.sh` 有檔案鎖，上一次還沒跑完就略過。log 在 `logs/daily_YYYYMM.log`。要停用就刪掉那兩行 crontab。

線上 Artifact 連結不會被排程自動更新，只有本機檔案會。

## 發佈到 GitHub Pages

- 原始碼在 `main`，網頁在 `gh-pages` 分支（每次部署都是**單一 commit 強制覆蓋**，所以每天的頁面與資料不會累積在 repo 裡）。
- `python3 gfd.py build --public` 產生 `docs/index.html`：和本機版相同，但**新聞只留標題與原文連結、不含摘要**，避免公開轉載鉅亨網內文；頁尾會標示這是公開示範版。
- 公開版另外產生 `docs/data/*.json`：事件衝擊、訊號劇本、沙盤推演、完整日線、鉅亨每日（最新一天／全部）這幾塊占了資料的八成以上，拆出來**用到才下載**，頁面本身約 0.9 MB（gzip 後約 0.27 MB）。頁面裡的資料網址帶內容雜湊（`?v=`），內容沒變就沿用瀏覽器快取。頁面畫好、瀏覽器閒下來後，會在背景先下載事件衝擊、訊號劇本、沙盤推演、最新一天的鉅亨每日（省流量模式與 2G／3G 連線不會）；完整日線在打開「單一標的」時才下載。本機版 `dashboard.html` 仍是單一檔案（file:// 不能下載其他檔），同樣的資料放在頁面裡另外的 JSON 區塊，用到才解析。
- `./deploy_pages.sh` 把 `docs/index.html` 與 `docs/data/*.json` 推上 `gh-pages`（推之前檢查頁面引用的資料檔都在、雜湊對得上，不對就不推）；`run_daily.sh` 每天更新完會自動呼叫它，所以 demo 跟著本機一起更新（電腦關機那天就不會更新）。
- 推送用 `gh` 的 git credential helper，不需要另外存 token。要停止公開更新：刪掉 `run_daily.sh` 裡呼叫 `deploy_pages.sh` 那段，或在 GitHub 設定關掉 Pages。
- `data/`、`logs/`、`docs/` 都不進版控，repo 只有原始碼（33 個檔案）。

## 事件衝擊鏈怎麼算的

回答「某件事發生後，兩週到兩個月內錢往哪流」。用**日線**（月資料做不出兩週的尺度），事件是**真的發生過的事**，不是價格門檻。設定在 `gfd/config.py`（`SHOCK_EVENTS`、`CASCADE_*`），量測在 `gfd/cascade.py`，日線存在 `data/raw/daily_cascade.json`（不進版控）。

43 個標的分五層：上游原物料與能源價格 → 中游能源與資源股 → 中游工業、運輸與石化鋼鐵（含長榮、陽明、中鋼、台塑、台塑化）→ 下游終端需求與科技股（含日經、DAX、富時）→ 資金面利率匯率避險。

### 1999 年以前的事件：代理序列

ETF 與期貨大多 1999–2000 年才有日線，所以 1980–1999 的事件用**代理序列**接在前面（`CASCADE_PROXY`）：只取代理在主序列開始日之前的報酬，接點以主序列第一天的價位對齊，接點之後完全是原序列。

| 標的 | 代理 | 起始 |
|---|---|---|
| WTI 原油 | 美國能源資訊署 WTI 現貨日價（網頁週表解析） | 1986-01 |
| 黃金、白銀 | 倫敦金銀市場協會（LBMA）定盤價 | 1968 |
| 台灣加權 | 證交所 FMTQIK 每日加權指數（快取在 `data/raw/twse_taiex_hist.json`） | 1990-01 |
| 那斯達克 100 | 那斯達克綜合指數 | 1971 |
| 能源、原物料、運輸、零售、必需消費、科技、半導體、公用事業、金融股 | Fidelity Select 產業基金**還原淨值**（未還原的話配息日會假跌） | 1981–1986 |
| 金礦股 | 費城金銀礦業指數 ^XAU | 1983-12 |
| 長債、高收益債 | Vanguard 長期公債基金、高收益公司債基金 | 1986／1980 |

沒有代理的（銅、穀物、天然氣、個股、日圓、新台幣）在早期事件中就是缺資料，頁面會寫「43 個標的中只有 N 個在當時有資料」。代理與原標的不是同一個資產（例：Fidelity 半導體基金 ≠ 費城半導體指數），明細逐筆標註。

**傳導順序是量出來的，不是假設的**：

1. 先判斷有沒有**實質反應**：事件後 42 個交易日內，最大累積變動要超過該標的自身 2σ×√天數（σ 取事件前 60 個交易日的日波動）。沒有就標「無實質反應」，不給速度。
2. 有反應的才算**傳導速度**＝累積變動達到「最大反應一半」的那一天。上游通常幾天就走完，下游會拖。
3. 另外記錄事件前 10 個交易日的變動（看有沒有提前反映）、兩週／一個月／兩個月的變動。

### 實際量到的例子

- **俄烏入侵（2022-02-24）**：WTI 原油與小麥第 5 天走完一半（峰值 +29.5%／+30.4%）→ 銅、玉米第 6 天 → 天然資源股第 7 天 → **台積電與台股第 8 天**（兩個月 −17.2%／−10.2%）。
- **Abqaiq 油設施遇襲（2019-09-14）**：38 個標的只有 4 個有實質反應——原油與**台塑化**都在第 1 天（+13.7%／+7.2%），利率與台積電要到第 14～16 天。
- **雷曼破產（2008-09-15）**：利率第 1～3 天先動，商品與股市第 15～16 天才走完一半。

### 和「平常」比，並做多重檢定

分類彙總與類型比較的每一格都附**無條件基準**＝該標的全部歷史中任意一天起算同樣天數的中位數與上漲比例（S&P 500 平常一個月就有 64% 機率上漲、中位數 +1.24%），否則長期上漲的資產在任何事件後都像「錢流入」。事件後上漲比例和平常的差異用單尾二項檢定。

**多重檢定的結果（2026-10-01，五個視窗）**：2,365 格比較中 120 格 p≤0.05；把每個事件日隨機移到前後三年內重跑 20 次，假事件平均也有 92.8 格過關——**估計約四分之三是運氣**（視窗從三個加到五個，檢定變多，運氣比例也跟著升）。比較可信的（次數多、p 很小）：

- 金融危機後兩週：原物料股、加拿大 TSX、DAX、S&P 500 下跌（9–10 次中只有 0–2 次上漲，平常 56–60%）；一個月後**黃金上漲 10 次中 9 次**（平常 52%）
- 央行轉向後：10 年殖利率兩個月中位數 +34bp（12 次中 10 次上升，平常 48%），公用事業股與長債下跌
- 戰爭與地緣衝突後兩週：**恆生指數 14 次中 12 次下跌**（平常上漲 54%）

同一類事件的起因不同，4～5 次的類型（選舉、科技、疫情、天災、貿易政策）即使全部同方向也可能是巧合。

### 持續性：短暫／長期／一年以上（2026-10-01 課堂）

每個有反應的標的，用兩個月內的最大反應當尺：半年後還保有一半以上（同方向）算「長期」，一年後還保有一半以上算「一年以上」（只量到一年，不用課堂的「永久」）；否則「短暫」。事件層級取多數。88 個事件中 56 個短暫、25 個一年以上、6 個長期；廣場協議 8 個有反應的標的裡 6 個是一年以上。

**一定要看基準**：隨機挑 200 個日期當假事件，有反應的標的也有約四成被判成「一年以上」（長期上漲的漂移，加上半年、一年的波動本來就比兩個月大），而真實事件反而只有約三成——所以「一年以上」本身不代表事件特別持久，要比隨機日期高很多才算（頁面上每個事件都附這個對照）。

課堂說中國事件常被政策壓住、約半年後才浮現：用「兩個月內有反應的標的中，半年後比兩個月的峰值更大」的比例檢驗，中國事件（`CASCADE_CN_EVENTS`，7 次）中位數 33%、其他事件 25%，但平均數幾乎一樣（29% vs 31%）、隨機日期也有 32%，重排檢定 p≈0.34——**差異在隨機範圍內**，資料不能證明、也不能否定，次數太少。

### 其他處理

- 同一類裡相隔不到 30 天的事件，彙總時只算較早那個（`CASCADE_DEDUP_DAYS`），避免同一段價格路徑算兩次；單一事件頁會標出 60 天內有哪些其他事件（視窗互相污染）。
- 事件發生在收盤後或週末時，日期填消息公布日，基準自動取那之前最後一個收盤（例：2023-05-25 輝達財測以 5/24 收盤為基準；台股在 DeepSeek 衝擊時休市，基準自動退到 1/22）。
- 2020-04-20 WTI 期貨結算為負值，對數報酬無定義，當天略過。

限制：分類彙總的中位數只能當參考；事件期間常伴隨其他事件，無法分離因果；概略日期的事件已標註。

### 現在像哪次（`gfd/analogs.py`）

把今天的市場狀態（S&P 20／60 日變動、距一年高點、20 日波動、10 年殖利率 20／60 日變動、殖利率曲線、美元、黃金、原油、高收益債）加上最新一天的反應幅度（以事前 60 日波動為單位），和 88 個事件發生時比對，列出最像的 5 次，以及它們**見報之後**（從事件第一天收盤起算）兩週／一個月／兩個月的變動。今天的收盤由每天更新的 `detail.json` 接在歷史日線後面。

**這個方法先回測過，結果是沒用（2026-09-29）**：對每個事件假裝不知道結果，用最像的 5 次其他事件（排除前後 60 天內的事件）預測它事後比平常漲多還跌多——

| 預測方法 | 兩週 | 一個月 | 兩個月 |
|---|---|---|---|
| 狀態最像的 5 次事件 | 53.7% | 51.3% | 51.2% |
| 同類型事件 | 52.3% | 49.8% | 46.9% |
| 隨機挑 5 次事件（300 輪平均） | 51.5% | 50.1% | 50.4% |

隨機 300 輪中命中率不輸相似事件法的占 8%／25%／30%，都沒有低於 5%；同類型事件在兩個月反而比 98% 的隨機輪差。**「歷史上像現在的時候發生過什麼」只能當對照，不能當買賣訊號**，頁面上把這段結論放在最前面。回測結果快取在 `data/raw/analogs_backtest.json`。

## 傳導鏈怎麼算的

先寫下經濟學上的假說（例如「日債殖利率上行 → 日圓升值 → 美股下跌 → 費半 → 台股」），每一層都給可判定的觸發條件，再用 1995 年以來的月資料逐段檢定。鏈與條件都在 `gfd/config.py` 的 `CHAINS`，量測在 `gfd/chains.py`。

每段連結量測四件事：

1. **傳導機率**：上游成立後 6 個月內，下游條件跟著成立的比例，對照「任意時點」的無條件基準。
2. **等待時間**：下游條件第一次成立要幾個月（中位數）。
3. **報酬分布**：下游標的在事件後 1／3／6／12 個月的中位數、上漲比例、最糟一次、期間內最大逆行，全部對照無條件基準；p 值用觸發序列循環位移 2000 次的雙尾比例。
4. **先行 vs 追價**：事件當下下游自己前 3 個月動了沒，兩組之後 3 個月的報酬分開比。

事件數是**合併後的獨立事件**（間隔 ≤ 3 個月算同一次），不是重疊月數。

### 目前的結論（每次重算會更新）

- **傳導本身大多成立**（2026-10-02）：27 段裡 15 段的下游條件出現機率比平常高 10 個百分點以上。最強的是 VIX ≥ 30 → 高收益債下跌（58% vs 平常 21%）、S&P 下跌 → 費半下跌（95% vs 60%）。
- **但「跟著發生」不等於「能賺錢」**：只有 3 段的事件後報酬在統計上站得住（恐慌反轉鏈的前兩段、肥料鏈的 10 年殖利率 → 3 個月利率）。其餘與平常沒有明顯差別。
- **「見報就是出場點」不是普世規則**：可比較的 22 段中 11 段是「下游還沒反應時進場」較好，方向大致是恐慌與下跌鏈偏反轉、景氣與上漲鏈偏動能。兩邊事件數都不多。
- 全鏈同時成立的次數通常只有 1～6 次，只能當歷史紀錄看。

這些都是樣本內的歷史統計，沒有做樣本外交易驗證，也沒有計入交易成本與流動性。

## 訊號劇本怎麼算的

回答「出現某個訊號時，錢放哪歷史上比較好」。設定在 `gfd/config.py`（`PLAYBOOK_*`），量測在 `gfd/playbook.py`。

- **前兆**：哪些訊號常在事件前 6 個月出現。同時給**精確率**（前兆出現後事件真的發生的比例）與**召回率**（事件有多少次事前看得到這個前兆），只看其中一個會誤判。
- **期望值＝超額**：事件後報酬中位數 **減掉該資產自己的無條件基準**。不扣基準的話，長期上漲的資產會一路排在前面，那不是訊號帶來的。
- **樣本外**：以 2012 年切成前後兩段，兩段中位數必須同方向才列入。
- **月均價要從下個月算起**（2026-10-02 修正）：世界銀行商品價格與央行匯率是「月均價」，月底做決定時當月均價已經包含過去半個月，從它算起的「之後報酬」等於偷看了半個月。`chains.forward` 對 `AVERAGED_SERIES` 一律從下個月的均價算起，並且只用已收完的月份。修正後可投資的穩健組合由 77 組剩 46 組（全部穩健組合 117 → 86；清單顯示的前 60 組中消失的 36 組全是月均價標的，例如「農產品指數 6 個月漲 ≥ 8% → 能源指數 6 個月 +19.7%」），估計偽發現率由 39% 升到 64%；傳導鏈裡報酬顯著的 3 段不受影響。
- **可投資 vs 觀察指標**：VIX、殖利率、利差不能直接買進持有，事件後又常有機械性反應；人民幣中間價與波動區間由政策設定、方向受政策引導（2026-10-01 課堂：不建議操作）。這些在 `OBSERVE_REASONS` 列出原因，KPI 卡片標「觀察用」，訊號劇本分開呈現。

### 多重檢定：這一步不能省

一次檢定三千多組（訊號 × 資產 × 期間；下表是 2026-09-24 的 3,549 組，2026-10-01 加了訊號後是 3,882 組；2026-10-02 修正月均價的時間點後估計偽發現率 64%，最新數字以頁面為準），光靠運氣就會撈到一批「有效」結果：

| p 值門檻 | 實際通過 | 運氣預期 | 估計偽發現率 | 加上前後半期一致與幅度門檻 |
|---|---|---|---|---|
| p ≤ 0.10 | 474 | 355 | 75% | 292 |
| p ≤ 0.05 | 268 | 177 | 66% | 187 |
| **p ≤ 0.02（採用）** | **137** | **71** | **52%** | **102** |

**虛無校準**：把事件時點整體隨機位移後，用完全相同的流程重跑 3 次，在「確定沒有訊號」的資料上分別有 37、54、61 組通過全部門檻（平均 50.7）。實際資料留下 102 組（可投資 67 組），所以**估計約一半是運氣**。這個比例是量出來的，不是假設的（先前版本曾用「篩選大概濾掉一半」的假設估成 35%，低估了雜訊）。

**方向與假說相反的結果會自動標記**：例如「日圓 3 個月升值 ≥ 2% → 費城半導體 6 個月超額 +11.1%（p=0.002）」與日圓套利平倉鏈的敘事相反（該鏈預期日圓升值時半導體走弱）。這種結果要嘛是統計假象，要嘛代表這個訊號反映的其實是別的機制（例如日圓升值常伴隨降息預期與美元走弱），清單中以 ⚠ 標示，不要直接照用。

註：這裡刻意不用 Benjamini-Hochberg。循環位移檢定只有約 381 種位移，p 值下限約 0.005，BH 在三千多次檢定下會要求 p < 0.00003，那是這個檢定做不到的精度，用了會把「精度不足」誤報成「完全沒訊號」。改用「運氣預期值 ÷ 實際通過數」估偽發現率。資產彼此相關，實際偽發現率可能更高。

所有統計都沒有計入交易成本、滑價、稅負與流動性，也不是投資建議。

## 沙盤推演怎麼算的

回答「現在這些訊號亮著，接下來可能怎麼走、哪些標的期望值較好」。設定在 `gfd/config.py`（`SCENARIO_*`），計算在 `gfd/scenario.py`，`gfd.py analyze` 時一起算、存在 `analysis.json` 的 `scenario`。

- **現況**：直接用訊號劇本的「亮燈」判定（各序列最新一筆），兩個檢視的數字一致。
- **傳導鏈推演**：每條鏈從目前成立的層往下，還沒成立的層「在上游成立、這一層當下還沒成立時，6 個月內跟著成立」的歷史比例，對照「這一層當下沒成立的隨便哪個月」的平常比例，以及成立時中位數等幾個月；如果那一層也成立，訊號劇本裡通過三道檢驗的組合是什麼。
- **期望值**：每個可投資標的「之後 h 個月報酬 − 自己平常的平均」，對全部約 40 個訊號的 0/1 指標做 ridge 迴歸（λ＝24，事先設定、沒有看樣本外結果挑）；目前亮燈訊號的係數加總＝模型期望超額。區間是 12 個月一塊的區塊自助法。
- **樣本外檢查**：從 2005-01 起每個月只用當時已知結果的資料重估，買期望值最高的 5 個，和當期全體平均比。期間互相重疊，所以每隔 h 個月取一期、每個起點各算一次，附置換檢定；同時算兩種對照（單一訊號平均、過去 6 個月動能）。月均價標的（世界銀行商品、央行匯率）的報酬從下個月的均價算起、估計時多退一個月——第一版沒有這一步，3 個月的差距被灌成 +1.43 個百分點、判成「有效」，驗收抓到後修正。2026-10-02 修正後的結果：3 個月 +0.35（不同起始月 −0.40～+0.90）、6 個月 +1.11（−0.93～+2.86），都是「時好時壞」；12 個月無效。**也就是說，這套排名目前還不能當買賣依據**，頁面照實寫。
- **校準**：樣本外實際超額大約只有模型值的 0.1～0.15 倍，頁面以「模型值 × 校準斜率」為主要數字；回測判定無效的期間不給校準值。
- **更深一層**：傳導鏈每個還沒成立的層同時給 6 個月與 12 個月內成立的比例（對照平常）；再照每條鏈「現在的狀態」（亮著的層都亮、其餘都沒亮）找歷史月份，看剩下的層 12 個月內全部走完的比例。另外跨鏈找「下一波可能亮起的訊號」：和現在相似（亮燈訊號重疊 ≥ 25%）的月份，之後 6 個月哪些現在沒亮的訊號比平常更常亮起。2026-10-02 看到的例子：台股 3 個月跌 ≥ 5% 在 6 個月內比平常更可能（61% vs 42%），但拉到 12 個月就和平常一樣（66% vs 69%）。
- **每個訊號的年齡**：目前這一段（間隔 ≤ 3 個月的中斷算同一段）已經亮了幾個月，和歷史上已結束的各段比（中位數、最長、撐到這麼久的比例）；另列單獨看這個訊號之後 6 個月最好／最差的可投資標的（訊號劇本口徑，p ≤ 0.10）。2026-10-02 的例子：日本 10 年殖利率的訊號這一段已 20 個月，歷史 14 段最長只有 10 個月。
- **每條鏈從最深的一層往下**：歷史上「目前最深那層亮著、它下面的層都沒亮」的月份（中間被跳過的上層不算），之後 12 個月下面的層再亮幾層的分布、緊接的下一層 6 個月內亮起的比例、那層熄掉（照段的規則，連續熄超過 3 個月）又沒傳到下一層（斷鏈）的比例，以及末端標的 6 個月報酬依「下一層有沒有亮」分組；下一層本身就是末端時不分組（末端的報酬和它自己的觸發條件是同一件事）。2026-10-02 的例子：日圓套利鏈從費半下跌往下，歷史 20 段中台股 6 個月內跟著跌 61%、12 個月內 66%、斷鏈 29%；通膨鏈從 10 年殖利率上升往下，那斯達克 6 個月內跌 ≥ 3% 只有 23%、斷鏈 54%，有跌時黃金 6 個月中位 −4.2%（9 次）、沒跌時 +3.1%（30 次）。
- **每個案例的故事**：之後一年內收錄的事件、各鏈實際走到第幾層、6 個月實際最好與最差的標的（事後資料，只做對照）。
- **對答案**：挑出亮燈訊號和現在重疊 ≥ 25%、彼此至少隔一年的歷史時點（2026-10-02 是 12 個：1999-12、2002-04、2003-11、2006-05、2007-10、2009-06、2011-02、2013-08、2017-01、2018-02、2021-03、2022-03），在每個時點只用當時已知的資料重跑期望值排名、傳導鏈下一層、下一波訊號，再對照之後實際發生的事。2026-10-02 的結果：當時模型 3 個月前 5 名跑贏全體 6/11 次（置換檢定 p≈0.27，分不出和亂挑的差別）、6 個月 7/11 次（p≈0.07）；傳導鏈下一層的機率比直接用平常比例還不準（Brier 0.251 vs 0.226）；下一波訊號 37 個中亮起 18 個（49%，平常約 43%，p≈0.26）。今天的前 5 名放回這些時點看起來不錯，但那是樣本內（今天的模型就是從這些歷史學來的），頁面明講不是公平的考試。
- **原因**不用 ridge 係數說（同時亮著的訊號會互相分攤，單看係數會出現看不出道理的拆法），改列每個訊號「單獨」的歷史（訊號劇本口徑）、最像現在的歷史時點之後的實際結果、它在傳導鏈裡的位置、相關事件類型（事件衝擊・日線）的短期反應。訊號劇本的穩健組合標成「檢驗支持」或「檢驗相反」，不能只寫「通過檢驗」。
- **可信度（2026-10-03，使用者要求「讓它有參考價值」）**：先用 2005 年起每個月的走步對答案量每一種推論（`_chain_reliability`、`backtest.halves`、`ensemble.dir_hit`，結果在 `scenario.reliability` 與 `backtest`；研究腳本在 `research/`），只採用前後半（2005～2015／2016 起）都站得住的改法。**結論要照實寫：量完之後，多數推論仍只有一點跡象。**
  - 傳導鏈下一層的機率照段數往平常收縮（`_shrink`，K=20；`prob_adj`）。802 次走步預測（27 段連結）：原始 Brier 0.255 比直接用平常 0.238 還差，收縮後 0.236、和平常持平（區間跨 0）。收縮後各箱大致只分得出低（40% 以下）和高兩檔，最大偏差 16 個百分點（寫 40～50% 的實際 61%）。頁面與避險的機率一律用收縮後，原始值在提示裡。K 是在 {5,10,20,40,80} 的格點上以全樣本挑的（20 與 40 一樣），12 個月的收縮沿用同一個 K、沒有另外走步驗證。
  - 「比平常更可能」改用收縮後差距 ≥ 5 個百分點：170 次提示實際發生 64%、平常 57%（差 +7，以年為塊的 95% 自助區間約 −7～+17，前半 +1.6、後半 +9）→ 頁面寫「有一點跡象，統計上還分不出和運氣的差別」；判定「有參考價值」要兩半都 ≥ 3 個百分點且區間下界 > 0，目前沒達到。「更不可能」138 次 58% 對 59%、前後半方向相反 → 沒有參考價值。
  - 排行改用「模型＋相似時點」的集成（`_knn_pred`：亮燈組合重疊 ≥ 25% 的歷史月份之後的中位超額，和模型值取 % 平均）。3／6 個月前後半都正（+0.47／+0.71、+0.87／+2.12；原模型 +0.52／+0.25、+0.66／+1.47），12 個月前半仍為負（−0.57／+1.31）；判定都是時好時壞，單一標的的超額方向命中只有 51～52%。集成的校準斜率 < 0.05 時不給校準值（12 個月）。單用相似時點在 3／6 個月的全期平均略高於集成，但前半（2005～2015）接近 0，所以採用兩半都正的集成。「對答案」卡的「今天的前 5 名」跟著改用集成排序，所以 2026-10-03 那欄的數字變了（6/11）。
  - 試過但沒用的：位階（低基期）當排行依據每個期間都是負的；用前半挑資產到後半不成立；兩角度一致也沒有方向技巧（52～55%）。
  - 推演總結加「可信度計分板」卡（`web/js/68-reliability.js`）：每種推論一列，成績與判定全部由資料組出來。新增的抽樣用獨立的亂數（`SEED+100+h`、`SEED+7`），原本的區間與判定不受影響。
- **限制**：訊號與門檻是事後設計的，回測只排除了估計上的偷看；比較過不只一種組合方式，挑選本身也是偷看；對數報酬、沒有交易成本。現在這組訊號完全相同的組合歷史上沒有出現過（最像的只有 0.4 多的重疊），期望值是組合推估。

## 避險怎麼算的

回答「如果真的跌了，手上什麼會漲、能補回多少、平常要付出多少」——和期望值排行（哪個之後漲比較多）是不同的問題。設定在 `gfd/config.py`（`HEDGE_*`），計算在 `gfd/hedge.py`，`gfd.py analyze` 時接在沙盤推演後面算、存在 `scenario.hedge`（跟著沙盤推演那包延後下載）；算失敗只會略過這一塊，不影響每日更新。

- **跌段**：用傳導鏈同一個下跌條件（台股 3 個月跌 ≥ 5%、S&P 500 與那斯達克 100 跌 ≥ 3%、費半跌 ≥ 5%，對數報酬），發生機率也直接取傳導鏈算好的數字（同一個節點在幾條鏈出現就列幾條，大字取最高的）。亮燈月份間隔 ≤ 3 個月算同一段，每段取最深的那 3 個月：一段只算一次，2008 年這種長跌段不會重複算十幾次。2026-10-02：台股 23 段、S&P 500 20 段、那斯達克 26 段、費半 26 段（最近一段 2026-06→09 還沒結束）。
- **同一個窗的報酬**：月底收盤到月底收盤的一般報酬（可以直接拿來算配置）。黃金、原油、匯率等月均價序列改用 Yahoo 月線收盤（`detail.json` 的 `m`），才不會和指數錯開時間；債券基金、波克夏用原本的月資料（含配息）；只有月均價、沒有收盤價的商品指數（`ci_*`）不列。月線收盤會先拿掉「單月跳出去又跳回來 2 倍以上」的錯值（例：Yahoo 的 TWD=X 在 2014-12 有一筆 3.67，沒拿掉時「美元平常每 3 個月 +2.7%」）。美元/日圓改列「持有日圓」那一邊（反向）。
- **每項資產**：上漲段數（保護率）、中位數、最差一次、其他時候（不在跌段的 3 個月窗）的中位數；置換檢定＝隨機挑同樣多個 3 個月窗，中位數不低於跌段中位數的比例（小＝跌的時候特別會漲，不只是平常就在漲）。判定只看全部跌段：穩定避險（中位 > 0、上漲 ≥ 70%、p ≤ 0.10）、有點幫助（中位 > 0、上漲 ≥ 55%）、跟著跌（中位 ≤ −2%、上漲 ≤ 35%）、沒幫助、樣本不足（< 8 段）。四個情境合起來約 100 次檢定、沒有做多重檢定校正，頁面「怎麼算的」用當天的數字寫出來。2026-10-02：103 次裡 p ≤ 0.10 的 8 個（全是運氣也會有約 10 個）、p ≤ 0.01 的 2 個（運氣約 1 個）——整體來看「跌的時候特別會漲」的證據不比運氣多，只有美長債對 S&P 500 下跌（p≈0.0005）明顯超出運氣；對台股下跌，沒有任何一項達到 p ≤ 0.05（最好的是日圓 0.06、美長債 0.10），那些「有點幫助」多半是它們平常就在漲。
- **環境分組**：每一段開始時，哪些「現在亮著的訊號」也亮著；頁面上可以只看那些段。預設的對照是「美 10 年殖利率 6 個月上升 ≥ 40bp」（`HEDGE_REGIME`）——選它是因為機制明確（利率上行時股債常一起跌），不是看結果挑的；其他亮著的訊號在選單裡一樣能切換。這種段只有個位數，只畫出來對照、不下判定；列的順序固定用全部跌段排（換環境時不跳動），開頭結論也只講「同一項」在這幾段的結果，不在個位數段裡另外挑贏家。
- **配置試算**：每一段「(1 − w) × 目標 + w × 避險資產」的中位數與最差一次；其他時候的混合中位數在後端先算好（w = 0%～50%，每 5%），因為中位數不能拿兩個中位數線性相加。原幣計、沒有交易成本、每段期初配置一次。
- **2026-10-02 看到的**：全部跌段裡美長債最常同時上漲（台股 23 段中 17 段、中位 +3.1%；S&P 500 20 段中 15 段、中位 +6.0%，p < 0.001）；但跌段開始時利率已在上行的那幾段，美長債對台股只有 3/6 段上漲（中位 +1.2%）、對 S&P 500 只有 3/7（中位 −0.2%）、對費半 3/6（中位 −0.3%），和「利率上行時股債同跌」一致。其他資產在這幾段也只差一兩段（例：美元（對新台幣）對台股 3/4 段、中位 +2.2%），分不出誰比較穩，頁面上不在這種子集裡另外挑贏家。原油、費半、恆生、日經在台股跌的時候大多跟著跌——分散到其他股市或原油不是避險。
- **日線版（2026-10-03 加，頁面預設）**：月資料的 3 個月窗會把月中的急跌糊掉（例：2020 年 2 月底到 3 月），日線改看「波段高點 → 波段低點」：從高點跌超過門檻（台股、S&P 500、那斯達克 100 是 10%，費半 15%）算一段，之後從低點反彈超過同一門檻才確認見底（zigzag，一段只算一次，長空頭市場中間反彈夠大就切成好幾段）；1990 年起。各資產取同一天或之前最近一天的收盤（超過 7 天沒資料算缺值）；台股比美國早收半天，對幾週以上的下跌影響很小。債券基金用含配息的日線（`fetch_hedge_daily` → `data/raw/daily_hedge.json`，VUSTX／VWESX／VWEHX，和事件衝擊日線一起每週更新）；黃金、匯率、公用事業與必需消費股用事件衝擊的日線（價格，不含股息）。置換檢定把每一段換成同樣長度、隨機起點的視窗；環境用「高點前一個完整月」的訊號（當時已經知道的）；「其他時候」＝不和任何下跌段重疊、同樣長度（中位數交易日數）的視窗。日線版失敗只略過日線，月資料版照常。
- **日線版 2026-10-03 看到的**：台股 67 段（中位 32 個交易日、中位跌 −18.4%）裡，美元（對新台幣）有資料的 25 段（2004 年起）有 24 段上漲（中位 +1.8%，p≈0.0005；隨機同長度視窗只有 50% 上漲），利率上行時開始的 7 段全部上漲；美長債 47/67（p≈0.03），但利率上行時只有 7/12。黃金 31/67、中位 −0.7%，日線看不出避險效果（月資料版的「黃金 +2.3%」是 3 個月窗的結果）。四個情境 56 次檢定裡 p ≤ 0.01 的有 7 個（純運氣約 0.6 個）——和月資料版（103 次裡 2 個）不同，日線的結果明顯超出運氣：**對台股與費半下跌最穩的是持有美元，對 S&P 500 與那斯達克是美長債與美元**。總覽「各市場重點」的避險一則（`hedge.finding`）就是用台股的日線版組出來的，含換 20% 的試算。
  驗收時的敏感度測試：把來源收盤整體往前或往後挪一個交易日，台股的美元（對新台幣）24/25 變成 21–22/25、美長債 47/67 變成 43–47/67，p 值不變——上漲次數對同日對齊敏感、結論方向不敏感。下跌段在時間上會群聚（同一個空頭被切成好幾段），置換檢定把每段當獨立樣本，有效樣本比段數少，p 值可能偏樂觀；高點與低點都是事後才知道的，這是描述不是訊號。頁面「怎麼算的」都有寫。

## 設定

所有標的、龍頭股名單、危機區間、關聯配對、重點關鍵字與門檻都在 `gfd/config.py`。

- 龍頭股名單是大型權值股觀察清單，不是即時市值排名。
- 新聞重點：標題命中關鍵字 +2、鉅亨關鍵字命中 +1、鉅亨頭條 +2、提及龍頭股 +1（最多 +2）、標題提到當日異常波動的標的 +2；分數 ≥ `HIGHLIGHT_SCORE`（目前 7）標為重點。
- 異常波動：當日變動 ÷ 近 60 個交易日變動的標準差，絕對值 ≥ `MOVER_Z`（目前 2）。

## 價格口徑（哪個數字是什麼）

- **「收盤」只採用已收盤的價格**：交易時段還沒結束的市場（24 小時交易的外匯、期貨、VIX）顯示前一次收盤／結算，並標出日期；判斷依據是鉅亨 `session` 與 Yahoo `currentTradingPeriod`。
- **台股漲跌以證交所基準價計算**：除權息日用「除權除息計算結果表」的開盤競價基準，不是前一日收盤（例：台積電 2026-09-16 除息 7 元，收 2,380 為平盤），並在列上標註「除息 x 元」。
- **各分頁最上面的大數字卡片**＝最新已收盤價＋日漲跌（和鉅亨每日頁同一份數字）；12 個月漲跌用週線計算；30 年位階用研究用月資料。只有月資料的序列（例：台灣重貼現率）會標「月資料」。
- **研究用月資料**（折線圖、關聯、統計表）的當月數字是月初至今，每天更新；匯率與商品是月均值。
- 期貨收盤取 Yahoo 定稿後的日線（約台北中午後定稿），所以 07:30 那次匯入的期貨會是前兩天的結算價，18:30 那次才更新成前一天。

## 已知缺口

- **台灣／美國前 10 大公司債**：沒有免費的逐券長歷史，改用 VWESX／VWEHX／LQD／HYG 公司債基金。
- **台灣 10 年期公債殖利率**：沒有可程式化的長歷史，改用央行重貼現率。
- **港股公司現金流**、**台灣經常帳**：沒有免費結構化來源。
- **鉅亨網期貨、VIX、公債報價**：鉅亨公開 API 不提供這些代碼，每日頁改用 Yahoo／日本財務省並逐列標註。
- 匯率與商品是月均值，關聯係數會比用月底值略低。

## 檔案

```
gfd.py              CLI
gfd/config.py       標的與規則
gfd/sources.py      各資料來源轉接
gfd/history.py      抓 30 年資料 → data/raw/
gfd/analysis.py     統計與關聯研究 → data/analysis.json
gfd/scenario.py     沙盤推演（亮燈訊號 → 傳導鏈下一層 → 期望超額＋樣本外回測），併入 analysis.json
gfd/targets.py      確切標的、低基期、三個角度的推演、情境的幅度與等待分布，放在 analysis.json 的 scenario.targets
gfd/hedge.py        避險（跌段中各資產的報酬、環境分組、配置試算；月資料版＋日線版、總覽的避險一則），放在 analysis.json 的 scenario.hedge
gfd/daily.py        鉅亨每日 → data/daily/YYYY-MM-DD.json
gfd/build.py        內嵌資料 → dashboard.html、dashboard.artifact.html；--public → docs/index.html＋docs/data/*.json
web/                版面、樣式、前端程式（純 SVG 圖表，無外部函式庫）
```

所有統計都是歷史樣本內的描述，不構成投資建議。

相對強弱是價格變動排行，不是資金淨流量。每列提供來源、截至月份及月底／月均等採樣口徑；程式資料鍵 `flowmap` 為相容舊版保留。TIC 持有量存量、經常帳收支餘額及公司現金流分別呈現，不將存量變化直接宣稱為跨境資金流。指數分區之後的報酬屬重疊樣本的歷史描述，未完成樣本外交易驗證。
