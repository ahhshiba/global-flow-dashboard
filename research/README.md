# 可信度研究（2026-10-03）

使用者要求「讓可信度提高、具參考價值」。先量，再改：三支腳本只讀 `data/`，不改產品。

- `reliability_eval1.py`：傳導鏈下一層的機率（2005 年起每個月走步，645 次）：原始 Brier 比直接用平常還差；照段數往平常收縮（K=5～80）後持平或略好；「比平常更可能」提示的方向有訊號。排行：相似時點（kNN）、位階（低基期）、集成 vs 現行 ridge。
- `reliability_eval2.py`：前後半（2005～2015／2016 起）確認：「更可能」兩半都成立、「更不可能」方向相反；相似時點後半很強、前半普通，集成兩半都正；位階當排行依據每個期間都是負的；相似時點對門檻（0.2／0.25／0.3）不敏感。
- `reliability_eval3.py`：收縮後機率的校準分箱；「兩個角度一致」的方向命中只有 52～55%；集成用 % 平均（產品採用的版本）；前半挑資產到後半不成立。

採用的改法在 `gfd/scenario.py`（`_shrink`、`_knn_pred`、`_chain_reliability`、集成回測）與 `web/js/68-reliability.js`；數字摘要在根目錄 README 的「可信度」一節。
執行：`python3 research/reliability_eval2.py`（約 20 秒）。
